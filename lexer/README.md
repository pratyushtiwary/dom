# HTML Lexer

This module is responsible to generate AST from a input string. This AST is then used by `buildTree`(this method is yet to be implemented) to build a dom tree using `ElementNode` objects which would give user the ability to query tree using CSS selectors.

## 10000 ft Overview

The brain of lexer can be found inside `index.js`, to maintain context between change in char seen a state machine is used which can be found inside `stateMachine.js`. The state machine keeps track of context of the surrounding chars.

## Deep Dive

The main loop inside `index.js` goes through each char and tries to categorize them into tokens, whenever an event happens, such as seeing a `<` char we notify the state machine. State machine helps us keep track of contextual data and label what we are currently seeing in the loop. Every transition in state machine is broadcasted to a listener which handles things like extracting text part from html and popping known void tags. Whenever we see a tag start we extract its name and push it to a stack, later when we see a tag end we pop the stack not until we find the same tag which is ending.

Thought experiment: Think of this all as a sheet of paper given to you and on top of it there's another sheet of paper which is slowly(char by char) revealing the things written in the sheet below, everytime you see `<` in the reveal you **assume** it is start of a tag, based on the next char you decide whether it really is tag start or not, same way the main loop uses state machine to keep track of tiny amount of contextual data.

## Usage

```javascript
const parseHtml = require("./lexer");

const inputString = `<!DOCTYPE html>
<html lang="en">
<head>
	<meta charset="UTF-8">
	<meta name="viewport" content="width=device-width, initial-scale=1.0">
	<title>Document</title>
</head>
<body>

</body>
</html>`;

console.log(parseHtml(inputString)));
```

## API

### parseHtml(inputString: string) -> Object

This method takes a html string and returns a nested object that represents the passed html string in tree form

### utils

These functions are used by `parseHtml` but some of them can be used for generic use cases

**NOTE: It is recommended to use `TransitionStrategyBuilder` if you are planning to add new function for transition switch**

#### TransitionStrategyBuilder

Helper class that helps to create transition strategies in a self documenting manner. Using this is recommended as if in future any global level conditional changes are required we would have single source that would be required to modified.

### StateMachine

This class is utilized by `parseHtml` to keep track of current context, please read [Deep Dive](#deep-dive) section to understand how this is used by `parseHtml` method

### Token

Token helps document all the possible state changes and the char they represent, each token contains a name and a char. The char in token is used to make decisions for state change and name is used for debugging mainly
